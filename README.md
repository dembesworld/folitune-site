# folitune-site

Fichiers publics de l'app FolliTune, servis par GitHub Pages à `https://dembesworld.github.io/folitune-site/` :

- `config.json` : configuration lue par l'app au lancement (version minimale, liens des stores, message, interrupteurs des fonctions en ligne).
- `shazam-token.json` : jeton ShazamKit pour Android, signé chaque mois par le workflow `.github/workflows/shazam-token.yml` (secret `APPLE_MEDIA_KEY_P8`). Ne pas modifier à la main.
- `politique-de-confidentialite.md` : la politique de confidentialité, à l'URL `…/politique-de-confidentialite`.

Le code de l'app est dans un dépôt privé.
